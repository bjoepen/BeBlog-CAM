# Build 010-F3 — Stock-Cutting Startup and Bounded Seed Bootstrap

F3 builds a complete single-layer startup reference from an initially uncut local stock region. No previously cleared disk is supplied. Native circle/capsule guide binding and E6E protect the source part throughout the generated local entry footprint and subsequent contour reference. This is still planned geometry, not manufacturing release or execution evidence.

The startup is explicitly full-width. `allowFullWidthStartup === true` is mandatory; otherwise the entire build fails. A linear pendulum ramp begins at the stock surface, then a target-depth traverse completes the whole short slot and returns to its center. The ramp alone is never credited as clearing the slot to final depth. Maximum ramp angle, explicit ramp/startup feeds, numeric reserves and the existing ramp budget apply. This transient slot is not represented as satisfying the below-180-degree steady cutting policy and is never a fallback for failed contour or bootstrap geometry.

The completed slot contains a rectangle with half-width equal to cutter radius R. Its half-length exceeds R plus the first bootstrap radius. The first radius is at most R/3, so every first-link/circle cutter footprint fits the rectangle's longitudinal span. Circumference exposure is bounded against its transverse strip, eroded by 0.000001 mm. With strip half-width h, the simultaneous upper/lower outside-angle sum attains its maximum over |y| <= r at y=0 or |y|=r; F3 uses the greater bound with an angular reserve. Independent samples use the actual cleared capsule, not this analytic formula.

Two complete semicircles finish the first bootstrap loop. Since its radius is smaller than R, E5C constructively derives a disk with no central hole. Each subsequent radial link and expanding full loop passes E6A against the previous disk before being credited. The concentric previous disk covers any annulus hole; older history is unnecessary. Radius progress and a 512-loop budget are explicit, with an exact shorter final step. Failed engagement, part protection or budgets return no partial startup or contour.

The final loop produces the seed required by the internally generated contour. A separately assessed inward bridge joins the contour apex, and the existing E6E ordered protected material assessment validates the complete contour reference. The part-protection enclosure used during construction is only a geometric bound; it is never counted as pre-existing free material. The only material credits come from the completed target-depth slot and completed, assessed circle sweeps.

Acceptance covers transformed circle/capsule guides, inside/outside, both loop windings, surface-to-depth entry, ramp/flat feeds, all phase transitions, final seed radius/depth, immutable inputs and exact bridge continuity. Independent source-part samples cover startup and bootstrap cutter footprints. Independent cleared-slot/disk circumference and disk-coverage oracles check every bootstrap cycle. Tests reject missing full-width authorization, tight engagement policy, excessive radius progress, overlapping local footprint, ramp/loop budgets and invalid depth. `check:010f3` runs in CI.

Release boundary: local full-width startup must be separately accepted by the caller. No claim of avoiding full-width contact during initial slot creation; the engagement limit starts with bootstrap circles and remains enforced on the contour. Actual stock geometry, tool cutting length, load/chip thickness, machine dynamics, safe-Z approach/retract, multi-depth scheduling, job/UI/persistence/preflight integration and NC release remain open.
