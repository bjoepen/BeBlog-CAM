# Build 010-E6B — Ordered Straight Trochoid Material Assessment

E6A's frozen start disk eventually rejects a long contour reference even if previous loops would have cleared useful material. E6B assesses the existing 010-C straight LINE/ARC reference in order. It changes no generated geometry and introduces no pocket strategy.

Each cycle consists of its incoming apex link, if present, and two complete semicircles. E6A bounds all these motions against the **previous** assumed free disk. No part of the current loop or link is credited during that assessment. Only after the entire cycle passes the caller's circumference-exposure policy may its full sweep contribute to the next assumed disk.

For loop radius `r` and tool radius `R`, a full circle's cutter footprint covers the annulus with radii `max(0, r-R)` through `r+R`. E6B checks that the previous disk contains the central hole with reserve. The union of that previous disk and the completed annulus therefore covers a disk at the new loop center with radius `r+R-0.000001 mm`. Older material history outside this one disk is discarded conservatively. The new disk is cleared only through the current target depth, even when the initial seed was deeper. This is a conditional statement about material removal by a planned, completed sweep, not evidence of machine execution.

The first cycle uses the supplied seed, with no special exemption. Failure returns no candidate segments, no final disk and no partial accepted chain; the failing cycle is identified. The API builds the reference internally so arbitrary incomplete or reordered loops cannot claim full-circle clearing. It inherits E6A's finite-data, depth, topology, numeric reserve and below-180-degree policy checks.

Acceptance demonstrates a 20.5 mm chain with 4 mm loops, a 3 mm cutter radius and 1 mm progress under a fixture 140-degree limit. The same path fails against a frozen seed. Increasing progress to 2 mm fails at the second cycle. Tests include short final progress, both sides and windings, rotation/translation, invalid parameters, first-cycle failure, shallower-depth propagation, unchanged inputs, independently sampled circumference exposure and coverage of each propagated disk. The fixture values are not cutting recommendations. The check runs in CI.

**Release boundary:** straight reference only, at one constant depth in a common frame, conditional on the initial seed and successful material removal by previous planned sweeps. Circumference exposure remains distinct from feed-relative radial engagement in millimetres, chip thickness and cutting force. Ramp entry, protected-part clearance, closed contour traversal, corners and manufacturing integration remain unproven. No UI, operation dispatch, persistence, preflight or NC release is enabled.
