# Build 010-E6E — Protected Cutter and Initial Seed Envelope

E6E adds a separate combined assessment for native circle and capsule references. Existing E6B/C/D conditional material APIs remain unchanged. The new API returns material geometry only when both ordered material assessment and full source-part protection pass; a protection failure returns no material candidate.

The source-bound native boundary proofs establish that every candidate center stays on the allowed side of the parallel guide. For a circle or convex capsule offset, source clearance is therefore at least the absolute signed offset. Subtract the actual cutter radius to bound the full cutter footprint. This explicitly rejects a cutter larger than the offset even if its center path passes. A 0.00001 mm reserve exceeds the existing circle/capsule boundary tolerances, and oversized coordinates are rejected under the finite precision budget.

The whole initial assumed disk must independently avoid the protected source region. For a circle, use center distance plus/minus disk radius. For a capsule, use distance to its source spine and the 1-Lipschitz disk bounds. Both inside and outside are supported. Tangency or insufficient reserve fails closed. A seed can satisfy E6C/D material assumptions while failing this part-protection requirement; the former 9 mm test seed does exactly that. A 7.1 mm disk passes the protected fixtures with positive clearance.

The reported `minimumPartClearanceMm` is a conservative lower bound after subtracting reserve. E6B's coverage construction then preserves that protection for every propagated disk: each lies inside the previous protected disk union the completed protected cutter sweep. No extra clearance is credited to the closing link. These are statements about conditional planned geometry, not machine execution or seed provenance.

Acceptance covers native circles/capsules, inside/outside, both loop directions, transformed fixtures, full native path parity and immutable inputs. Independent source-domain samples cover every cutter disk along loops and links (including closure), the initial seed and all propagated disks, and verify the reported clearance lower bound. Rejection includes overlapping/tangent seeds, oversized tools, zero allowance reserve, missing geometry, invalid tool/seed values and insufficient cleared depth. `check:010e6e` runs in CI.

Release boundary: one constant target depth and only the bound native circle/capsule references. The assumed seed must still have valid clearance provenance; ramp entry and actual initial stock removal remain unproven. Circumference exposure is not feed-relative radial engagement, chip thickness or force. General contours, corners, depth orchestration, UI, persistence, preflight and NC release remain closed. Fixture values are not cutting recommendations.
