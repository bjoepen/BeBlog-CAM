# BeBlog CAM 0.2.0-beta.1

**First public beta — macOS / Apple Silicon**

BeBlog CAM is a maker-friendly 3-axis CAM application built around one idea: keep the workflow understandable while keeping the machining truth rigorous underneath.

The working path stays deliberately simple:

**Bauteil → Rohling → Werkzeuge → Bearbeiten → Prüfen → Fräsen**

## What is in this beta

0.2.0-beta.1 includes practical DXF and native STEP/BRep workflows, stock and work-coordinate handling, tool and material integration, facing, contours, pockets, carve operations, drilling and helical bore milling, STEP-based machining, Z-Level roughing, 3D surface finishing, Job Preview, Simulation, Inspector, Preflight and NC generation.

Postprocessors are available for Estlcam, GRBL and LinuxCNC.

The release also includes the production-qualification work completed in Build 008: deterministic project handling and failure paths, canonical toolpath and safe-motion contracts, STEP model orientation, real-world Z-Level performance work and self-contained native macOS packaging.

## Native STEP support

This DMG contains the OCCT runtime required by BeBlog CAM. The native application was qualified without relying on the local OCCT development installation.

The production build therefore preserves the same native STEP/BRep path used during development rather than falling back to a reduced non-native application.

## Installation on macOS

This beta is **not signed with an Apple Developer ID and is not notarized by Apple**. macOS Gatekeeper can therefore block the first launch.

1. Open the DMG.
2. Copy **BeBlog CAM** to **Applications**.
3. Try to open BeBlog CAM once.
4. If macOS blocks the application, open **System Settings → Privacy & Security** and choose **Open Anyway** for BeBlog CAM.
5. Confirm the subsequent macOS prompt.

No global Gatekeeper deactivation or Terminal workaround is required.

## Beta status and known limitations

This is a **Beta / Production Qualification** release, not a claim that every machine/controller/material combination has been qualified.

The current downloadable binary is Apple Silicon only. The application is not Developer-ID signed or notarized. External Estlcam and physical-machine qualification remain deliberately manual. 4/5-axis machining, turning, production planning and enterprise workflows are outside the current scope.

Surface Carve was explored experimentally and rejected after real-world acceptance; it is not part of the production feature set.

## Before running a machine

BeBlog CAM is designed to make generated motion visible and inspectable, but CAM output must still be treated as machine instructions.

Use **Prüfen**, inspect Preview/Simulation and the generated NC, confirm work coordinates, stock, tool, feeds/speeds and machine limits, and retain the normal machine-side safety procedures before running a real job.

## Why this beta matters

The beta was not produced from a feature checklist alone. Build 008 was repeatedly exercised with real maker parts and real generated NC. That work exposed and resolved issues ranging from model orientation and repeated STEP calculations to Z-Level geometry performance and the portability of the native OCCT runtime.

The result is the first BeBlog CAM build intended to leave the development Mac and be used as a downloadable native application.

There is, of course, still a CAM flea. Its job remains unchanged: find the problems before the router does. 🐜
