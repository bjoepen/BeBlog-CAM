# Build 010-E6C — Ordered Native Circle Material Assessment

E6C extends E6B's conditional material history to native two-arc circular guides from 010-B. It derives the free side and effective uniform loop radius through E2, builds the existing E4 semantic reference internally, and requires the native-circle boundary proof before assessing material. Arbitrary candidate paths, non-circular guides and forged offset metadata are rejected.

Straight and circular references share a private ordered assessment. Each incoming link and complete two-semicircle loop must pass E6A against the previous assumed disk before the completed cutter annulus may advance that disk. Central-hole coverage, numeric reserves and target-depth propagation retain E6B semantics. No current-cycle removal is credited early. Failure returns no segments, bounds or final disk.

The final closing link is assessed separately against the last propagated disk. Its exposure bound is returned as `closingExposureBoundDeg`; straight references return null. The link earns no additional disk. A failed closure reports `failingCycleIndex === loopCount`, after the zero-based loop indices, and discards the entire candidate. Older cleared history and the initial seed are deliberately not retained for closure, so this check can conservatively reject otherwise feasible paths.

Acceptance covers inside/outside, both loop windings, reflected and rotated/translated guides, independent dense cutter-circumference samples for every loop/link including closure, independent propagated-disk coverage samples, native geometry parity, depth propagation, unchanged inputs, frozen-seed rejection, excessive progress, missing seed, invalid policy/data and non-circle/forged-guide rejection. Fixture values are not cutting recommendations. `check:010e6c` runs in CI, and E6B acceptance protects the shared straight implementation.

Release boundary: native circular cutter-center reference at one constant depth, conditional on initial clearance and successful previous planned cuts. The circular boundary proof protects the selected guide side; this does not establish the full seed/ramp/cutter-envelope safety of a manufactured part. Circumference exposure is distinct from feed-relative radial engagement, chip thickness or force. General closed LINE/ARC contours, corners, ramp entry, multiple-depth orchestration, UI, persistence, operation dispatch, preflight and NC release remain closed.
